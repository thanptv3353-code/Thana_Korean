### 01 · ສະຫຼະ ແລະການອ່ານພະຍາງ / 모음

01 · ຕົວອັກສອນແລະການອ່ານ

**ຈຳແນກ ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ ແລະອ່ານພະຍາງທີ່ຂຶ້ນດ້ວຍ ㅇ.**

ຮ່າງຂອງ THANA KOREAN ສຳລັບເຈົ້າຂອງກວດ. ຍັງບໍ່ມີສຽງທີ່ກວດແລ້ວ. ຄະແນນແບບຝຶກບໍ່ແມ່ນການປະເມີນສຽງ ຫຼືຜົນສອບທາງການ.

ຄຳອະທິບາຍ
ຮັນກຶລຂຽນພະຍັນຊະນະ ແລະສະຫຼະລວມເປັນກ້ອນພະຍາງ. ㅇ ຢູ່ຕົ້ນພະຍາງບໍ່ອອກສຽງ: ㅇ + ㅏ = 아. ຮູບສະຫຼະຕ້ອງຈຳແຍກກັນ; ㅓ ບໍ່ແມ່ນ ㅗ ແລະ ㅡ ບໍ່ແມ່ນ ㅜ. ບໍ່ໃຊ້ຕົວລາວແທນສຽງເກົາຫຼີຢ່າງຕາຍຕົວ. ຝຶກຊີ້ຮູບກ່ອນ ແລ້ວຈຶ່ງຝຶກຟັງກັບສຽງທີ່ກວດແລ້ວ.

ຄຳສັບ/ຮູບທີ່ຮຽນ
아 — ㅇ + ㅏ
어 — ㅇ + ㅓ
오 — ㅇ + ㅗ
우 — ㅇ + ㅜ
으 — ㅇ + ㅡ
이 — ㅇ + ㅣ

ຕົວຢ່າງ
ຝຶກອ່ານ: 아 → 어 → 오 → 우 → 으 → 이. ຊີ້ສະຫຼະຢູ່ໃນແຕ່ລະກ້ອນພະຍາງ.

ຝຶກຮຽງຕາມແບບ: 아 → 어 → 오

ຝຶກໃຊ້: ປິດຄຳແປ ແລ້ວອ່ານຕົວຢ່າງ; ຂຽນຄຳຕອບຈາກຄວາມຈຳ. ກວດຄຳສັບຄືນກ່ອນເຮັດແບບຝຶກ. ສຳລັບການອອກສຽງ ໃຫ້ຝຶກກັບສຽງທີ່ກວດແລ້ວພາຍຫຼັງ.

#### ແບບຝຶກ ແລະຄຳຕອບ / 문제와 정답

1. ㅇ + ㅜ ໄດ້ພະຍາງໃດ?

   1) 오
   2) 으
   3) 우

   **우**

2. ຂຽນພະຍາງທີ່ໄດ້ຈາກ ㅇ + ㅣ.

   이

3. ຈັບຄູ່ຄຳ/ຮູບກັບຄວາມໝາຍໃນບົດ.

   아 → ㅇ + ㅏ
   어 → ㅇ + ㅓ
   오 → ㅇ + ㅗ
   우 → ㅇ + ㅜ

4. ຮຽງສ່ວນຕ່າງໆຕາມລຳດັບຕົວຢ່າງໃນບົດ (ໃຊ້ທຸກສ່ວນ).

   1) 아
   2) 오
   3) 어

   **아 어 오**

### 02 · ພະຍັນຊະນະພື້ນຖານ / 자음

01 · ຕົວອັກສອນແລະການອ່ານ

**ຈຳແນກຮູບ ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ແລະປະສົມກັບ ㅏ.**

ຮ່າງຂອງ THANA KOREAN ສຳລັບເຈົ້າຂອງກວດ. ຍັງບໍ່ມີສຽງທີ່ກວດແລ້ວ. ຄະແນນແບບຝຶກບໍ່ແມ່ນການປະເມີນສຽງ ຫຼືຜົນສອບທາງການ.

ຄຳອະທິບາຍ
ວາງພະຍັນຊະນະກ່ອນສະຫຼະ: ㄱ + ㅏ = 가, ㄴ + ㅏ = 나. ການປ່ຽນຮູບຕົ້ນພະຍາງເຮັດໃຫ້ຄຳປ່ຽນໄດ້. ຮຽນຮູບແລະການອ່ານຄວບຄູ່ກັນ; ຢ່າສະຫຼຸບວ່າພະຍັນຊະນະໜຶ່ງມີສຽງລາວທີ່ແທນໄດ້ທຸກຕຳແໜ່ງ. ບົດນີ້ຝຶກຮູບຕົ້ນ; ສຽງທ້າຍຈະຮຽນໃນບົດຕໍ່ໄປ.

ຄຳສັບ/ຮູບທີ່ຮຽນ
가 — ㄱ + ㅏ
나 — ㄴ + ㅏ
다 — ㄷ + ㅏ
라 — ㄹ + ㅏ
마 — ㅁ + ㅏ
바 — ㅂ + ㅏ

ຕົວຢ່າງ
ອ່ານແລະຄັດ: 가 나 다 라 마 바. ຈັບຄູ່ຮູບຕົ້ນກັບພະຍາງ.

ຝຶກຮຽງຕາມແບບ: 가 → 나 → 다

ຝຶກໃຊ້: ປິດຄຳແປ ແລ້ວອ່ານຕົວຢ່າງ; ຂຽນຄຳຕອບຈາກຄວາມຈຳ. ກວດຄຳສັບຄືນກ່ອນເຮັດແບບຝຶກ. ສຳລັບການອອກສຽງ ໃຫ້ຝຶກກັບສຽງທີ່ກວດແລ້ວພາຍຫຼັງ.

#### ແບບຝຶກ ແລະຄຳຕອບ / 문제와 정답

1. ㅁ + ㅏ ໄດ້ພະຍາງໃດ?

   1) 나
   2) 바
   3) 마

   **마**

2. ຂຽນພະຍາງຈາກ ㄴ + ㅏ.

   나

3. ຈັບຄູ່ຄຳ/ຮູບກັບຄວາມໝາຍໃນບົດ.

   가 → ㄱ + ㅏ
   나 → ㄴ + ㅏ
   다 → ㄷ + ㅏ
   라 → ㄹ + ㅏ

4. ຮຽງສ່ວນຕ່າງໆຕາມລຳດັບຕົວຢ່າງໃນບົດ (ໃຊ້ທຸກສ່ວນ).

   1) 다
   2) 나
   3) 가

   **가 나 다**

### 03 · ຕົວສະກົດ ແລະກ້ອນພະຍາງ / 받침

01 · ຕົວອັກສອນແລະການອ່ານ

**ແຍກຕົວຕົ້ນ–ສະຫຼະ–ຕົວສະກົດ ໃນຄຳພື້ນຖານ.**

ຮ່າງຂອງ THANA KOREAN ສຳລັບເຈົ້າຂອງກວດ. ຍັງບໍ່ມີສຽງທີ່ກວດແລ້ວ. ຄະແນນແບບຝຶກບໍ່ແມ່ນການປະເມີນສຽງ ຫຼືຜົນສອບທາງການ.

ຄຳອະທິບາຍ
받침 ແມ່ນພະຍັນຊະນະຢູ່ລຸ່ມຂອງກ້ອນພະຍາງ: 가 + ㄴ = 간. ຄຳວ່າ 문 ປະກອບດ້ວຍ ㅁ, ㅜ, ㄴ. ㅇ ຢູ່ທ້າຍຕ່າງຈາກ ㅇ ທີ່ຢູ່ຕົ້ນ: 강 ມີສຽງທ້າຍ. ຢ່າເພີ່ມສະຫຼະຫຼັງຕົວສະກົດ. ການເຊື່ອມສຽງເວລາມີຄຳຕໍ່ທ້າຍຈະຝຶກກັບສຽງຈິງພາຍຫຼັງ.

ຄຳສັບ/ຮູບທີ່ຮຽນ
문 — ປະຕູ
산 — ພູ
강 — ແມ່ນ້ຳ
밥 — ເຂົ້າສຸກ/ອາຫານ
손 — ມື
집 — ເຮືອນ

ຕົວຢ່າງ
문: ㅁ + ㅜ + ㄴ. 산: ㅅ + ㅏ + ㄴ. ຊີ້ຕົວສະກົດຂອງແຕ່ລະຄຳ.

ຝຶກຮຽງຕາມແບບ: ㅁ → ㅜ → ㄴ

ຝຶກໃຊ້: ປິດຄຳແປ ແລ້ວອ່ານຕົວຢ່າງ; ຂຽນຄຳຕອບຈາກຄວາມຈຳ. ກວດຄຳສັບຄືນກ່ອນເຮັດແບບຝຶກ. ສຳລັບການອອກສຽງ ໃຫ້ຝຶກກັບສຽງທີ່ກວດແລ້ວພາຍຫຼັງ.

   1) ㄴ
   2) ㅜ
   3) ㅁ

   **ㄴ**

2. ຂຽນຄຳວ່າ “ເຮືອນ” ຈາກຄັງຄຳ.

3. ຈັບຄູ່ຄຳ/ຮູບກັບຄວາມໝາຍໃນບົດ.

### 04 · ຝຶກອ່ານຄຳ ແລະຄັດຂຽນ / 읽기 첫걸음

01 · ຕົວອັກສອນແລະການອ່ານ

**ອ່ານຈຳນວນພະຍາງ ແລະຈັບຄູ່ຄຳທີ່ພົບປະຈຳ.**

ຈຳນວນກ້ອນຮັນກຶລຊ່ວຍໃຫ້ແບ່ງພະຍາງ: 나무 ມີ 나 + 무, ສ່ວນ 학교 ມີ 학 + 교. ຢ່າແບ່ງຕາມຈຳນວນຕົວພະຍັນຊະນະ. ຄັດແຕ່ລະກ້ອນແລ້ວອ່ານເປັນຄຳ. ບົດນີ້ວັດການຈຳຮູບແລະຄວາມໝາຍ; ບໍ່ໄດ້ຕັດສິນຄວາມຖືກຕ້ອງຂອງການອອກສຽງ.

바다 — ທະເລ
학교 — ໂຮງຮຽນ
우유 — ນົມ
사람 — ຄົນ
나라 — ປະເທດ

ຝຶກຮຽງຕາມແບບ: 나 → 무

ຝຶກໃຊ້: ປິດຄຳແປ ແລ້ວອ່ານຕົວຢ່າງ; ຂຽນຄຳຕອບຈາກຄວາມຈຳ. ກວດຄຳສັບຄືນກ່ອນເຮັດແບບຝຶກ. ສຳລັບການອອກສຽງ ໃຫ້ຝຶກກັບສຽງທີ່ກວດແລ້ວພາຍຫຼັງ.
